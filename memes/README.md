# Meme Pack

Put your own meme images in these folders. The bot will choose a matching image when the reply context fits.

Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`.

Folders:

- `default`: fallback memes.
- `happy`: happy, cute, success, praise.
- `confused`: errors, uncertainty, awkward moments.
- `thinking`: checking, thinking, explaining.
- `comfort`: calming or comforting replies.
- `sleep`: bedtime, tired, late night.
- `food`: food and drink topics.
- `game`: Fortnite, Steam, Epic, games.
- `wolf`: Wendell, wolf, fluffy topics.

Keep images reasonably small. The bot will try to compress large images before sending.
